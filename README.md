# inHub — Personal Developer Website & Digital Hub

> **Live version:** [indama3ks.com](https://indama3ks.com)

`inHub` is a lightweight, responsive personal website and dev log hub built on ASP.NET Core Razor Pages. It serves as a central showcase for software projects, mobile games, and engineering articles.

## 🛠 Tech Stack
* **Framework:** ASP.NET Core 8.0 (Razor Pages)
* **Markdown Engine:** Markdig + YamlDotNet (Custom Service)
* **Frontend:** Clean CSS variables, Flexbox/Grid, Vanilla JS
* **Localization:** Bilingual Content Engine (EN / RU)

## 📦 Key Architectural Features
* **KISS Principle:** Zero unnecessary database dependencies; relies on custom local Markdown parsing.
* **Contextual Dev Logs:** Dynamic filtering connecting products to their chronological dev histories.
* **Monochrome UI System:** Dynamic light/dark theme toggling with SVG icon inversion.
